# Task 005: Paper Plan and Timeline

## Goal

Create a concrete paper plan for the PAPF project.

This should be a planning document, not a final paper draft.

## Read first

- `AGENTS.md`
- `CONTINUITY.md`
- `docs/research_brief.md`
- `docs/research_gap.md` if it exists
- `docs/related_work.md`
- `docs/lit_matrix.md` if it exists
- `docs/benchmark_spec.md`
- `docs/benchmark_schema_plan.md` if it exists
- `docs/system_design.md`
- `docs/implementation_plan.md` if it exists
- `docs/paper_outline.md`

## Create or update

- Update `docs/paper_outline.md`
- Create `docs/paper_plan.md`
- Create `docs/figures_and_tables_plan.md`
- Update `CONTINUITY.md` only if the project state materially changes

## Paper plan should include

1. Working title options
2. One-sentence thesis
3. Candidate contributions
4. Paper structure
5. Required evidence for each section
6. Figures and tables needed
7. Experiments needed
8. Related work sections
9. Claims that are currently unsupported
10. Risks of overclaiming
11. Recommended first submission framing

## Figures and tables plan

Create a list of likely figures/tables, such as:

- System architecture diagram
- Task-to-capability compilation example
- Benchmark task taxonomy
- Policy decision matrix
- Metrics table
- Baseline comparison table
- Failure mode examples
- User comprehension / consent burden results if a user study is later added

Do not invent results.

For every planned result table, mark it as:

- `TODO: requires experiment`
- `TODO: requires benchmark implementation`
- `TODO: requires user study`
- `TODO: requires literature verification`

## Requirements

- Do not write a full paper.
- Do not invent data.
- Do not invent citations.
- Do not claim final novelty.
- Make the plan actionable.
- Keep the tone research-oriented and cautious.

## Final output

Report:

1. Paper plan files created or updated
2. Recommended first-paper framing
3. Missing evidence
4. Next concrete implementation task
5. Whether `CONTINUITY.md` was updated
