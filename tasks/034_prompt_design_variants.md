# Task 034: Define PAPF Prompt Design Variants

Status: planned.

## Goal

Define PAPF-style prompt formats to test in the user study.

## Create or update

- `docs/permission_prompt_examples.md`
- `docs/user_study_protocol.md`
- `paper/papf_final.md`
- optionally `paper/tables/prompt_variants.md`

## Requirements

- Define prompt variants:
  - minimal prompt,
  - detailed prompt,
  - risk-highlighted prompt,
  - prompt with expandable explanation,
  - prompt with audit-log preview.
- For each variant, specify whether it shows:
  - task goal,
  - requested tool access,
  - data touched,
  - data to be sent externally,
  - redactions applied,
  - reason for confirmation.
- Keep wording concrete and non-technical.
- Align variants with study conditions and measures.

## Verification

- Each prompt variant has a concrete example.
- Prompt variants differ along explicit design dimensions.
- The study protocol states how variants will be compared or piloted.
