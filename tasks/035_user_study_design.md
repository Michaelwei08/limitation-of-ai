# Task 035: Design User Study Section

Status: planned.

## Goal

Add a user-study section that evaluates whether non-expert users can understand and act on PAPF-style permission prompts.

## Create or update

- `paper/papf_final.md`
- `docs/user_study_protocol.md`
- `docs/permission_prompt_examples.md`

## Requirements

- Define target participants as non-expert users of personal AI agents.
- Use realistic personal-agent tasks involving email, files, browser content, and communication tools.
- Compare PAPF-style prompts against baseline permission models.
- Include baseline conditions:
  - no granular permission prompt,
  - broad app-level authorization,
  - generic LLM-generated confirmation prompt,
  - PAPF task-scoped permission prompt.
- Define study flow, randomization or counterbalancing plan, and decision tasks.
- State whether the section is a planned study or a completed study. Do not report results unless actual data exists.

## Verification

- The user-study section distinguishes planned protocol from empirical findings.
- Baseline conditions are clear enough to implement.
- The study design can collect both usability and privacy decision outcomes.
