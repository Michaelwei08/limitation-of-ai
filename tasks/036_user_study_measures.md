# Task 036: Define Study Measures

Status: planned.

## Goal

Define quantitative and qualitative measures for evaluating PAPF-style permission prompts.

## Create or update

- `docs/user_study_protocol.md`
- `paper/papf_final.md`
- optionally `paper/tables/user_study_measures.md`

## Requirements

- Add quantitative measures:
  - prompt comprehension accuracy,
  - correct allow or deny decisions,
  - false allows,
  - false denials,
  - time to decision,
  - perceived control,
  - perceived trust,
  - consent fatigue,
  - NASA-TLX or a similar workload measure if appropriate.
- Add qualitative measures:
  - interview responses,
  - confusion points,
  - reasons for allowing or denying actions,
  - prompt wording and detail-level preferences.
- Define how each measure maps to the HCI/privacy research questions.
- Mark any standardized instrument use as planned until survey items are finalized.

## Verification

- Measures cover comprehension, decision quality, workload, trust, control, and fatigue.
- Each measure has a collection point in the study flow.
- No statistical results are reported before data collection.
