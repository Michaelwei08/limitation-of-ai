# Task 037: Add HCI/Privacy Hypotheses

Status: planned.

## Goal

Add explicit hypotheses for the PAPF prompt and consent study.

## Create or update

- `paper/papf_final.md`
- `docs/user_study_protocol.md`

## Requirements

- Add hypotheses:
  - H1: PAPF-style prompts improve users' ability to identify overbroad or unsafe agent actions.
  - H2: PAPF-style prompts increase perceived control over personal data.
  - H3: PAPF-style prompts increase decision time and may increase consent burden.
  - H4: users prefer concise prompts with expandable details over verbose permission explanations.
- For each hypothesis, identify dependent variables and baseline comparisons.
- Mark hypotheses as planned if the user study has not been run.
- Avoid claiming support for hypotheses without collected participant data.

## Verification

- Each hypothesis maps to at least one quantitative or qualitative measure.
- The paper does not state hypotheses as findings.
- The study protocol can test each hypothesis under the proposed conditions.
